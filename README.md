# 頁序 PDF

在瀏覽器裡合併、拆分與整理 PDF 頁面。檔案只在本機處理，不會上傳，頁面也不會向第三方發出請求。

## 功能

- 加入多份 PDF，點選頁面選取、拖曳排序（顯示插入位置；可一次拖多頁）
- 鍵盤排序：在頁面的選取按鈕上按 `Alt + ←/→`；觸控裝置可用工具列的「前移／後移」
- 旋轉、刪除所選頁面；刪除後 8 秒內可按「復原」或 `Ctrl/Cmd + Z`
- 合併並匯出成一份 PDF
- 拆分：指定頁碼範圍（如 `1-3, 5`，可用全形數字與 `，、～`），輸出成一份 PDF 或逐頁打包成 ZIP；有勾選頁面時會自動帶入
- 匯出檔名：全部頁面來自同一份文件時沿用其檔名，否則為「頁序」，並附上時間戳
- 中文等未內嵌字型的 PDF 也能正確預覽

## 已知限制

- **不支援加密或有密碼保護的 PDF**：加入時會提示並略過。
- 匯出（合併、拆分）後以下內容**不會保留**：
  - 書籤（大綱）
  - 可填寫的表單欄位
  - 文件內部連結（目錄跳轉等）
  - 文件屬性（標題、作者等）
- 處理在瀏覽器主執行緒進行，非常大的檔案匯出時介面會短暫停止回應。

## 開發

```bash
npm install
npm run dev
```

```bash
npm run lint        # ESLint
npm test            # Vitest 單元測試（src/lib）
npm run test:e2e    # Playwright 端對端測試（會先建置並啟動 preview）
npm run build
```

PR 會由 `.github/workflows/ci.yml` 跑 lint、單元測試、建置與端對端測試。推送到 `main` 會自動部署到 GitHub Pages（網站在 `/pdf-tool/` 子路徑，見 `vite.config.js`）。
